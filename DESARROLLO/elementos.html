Unidad II. HTML, XML y CSS

El lenguaje fundamental de la web: HTML

HTML es el lenguaje de marcado estándar para crear páginas web. Desde los conceptos básicos hasta las técnicas avanzadas, este curso te llevará desde cero hasta convertirte en un experto en HTML.

¿Qué es HTML?

HTML es un lenguaje de marcado que se utiliza para estructurar el contenido de una página web. Utiliza una serie de elementos (tags) para definir diferentes partes de una página, como encabezados, párrafos, imágenes, enlaces y formularios.

Conceptos Básicos de HTML

1. Estructura Básica de un Documento HTML

Tags y Elementos

  • <p> para párrafos
  • <h1> a <h6> para encabezados
  • <img> para imágenes
  • <a> para enlaces
  • <div> y <span> para agrupar contenido
  • <ul>, <ol> y <li> para listas

Atributos

  • src en <img>
  • href en <a>
  • id y class para identificar elementos

Avanzando en HTML

Formularios

Los formularios permiten a los usuarios interactuar con la página web. Utilizamos etiquetas como <form>, <input>, <textarea> y <button> para construir formularios.

Multimedia

HTML admite varios tipos de contenido multimedia, como imágenes, audio y video. Utilizamos etiquetas como <img>, <audio> y <video> para incrustar estos elementos en una página web.

Semántica HTML5

HTML5 introduce nuevos elementos semánticos que proporcionan un significado claro al contenido, lo que mejora la accesibilidad y el SEO.

  • <header>
  • <footer>
  • <nav>
  • <section>
  • <article>
  • <aside>

Buenas Prácticas y Recomendaciones

Validez del HTML

Es importante que el código HTML sea válido según las especificaciones del W3C para garantizar la compatibilidad y el rendimiento.

Accesibilidad

Diseña tus páginas web con accesibilidad en mente para que puedan ser utilizadas por personas con discapacidades.

Optimización para Motores de Búsqueda (SEO)

Utiliza etiquetas semánticas adecuadas y estructura tu contenido de manera lógica para mejorar la visibilidad en los motores de búsqueda.

Responsive Design

Asegúrate de que tu página web sea compatible con diferentes dispositivos y tamaños de pantalla utilizando CSS para el diseño responsivo.

Hiperenlaces: valores del atributo href

El atributo href crea un enlace a otra página o archivo. Además, también puede enlazar a una sección de la misma página, a un correo electrónico o a un teléfono.

Valores del atributo target

El atributo target en HTML se utiliza para especificar dónde se debe abrir el enlace cuando un usuario hace clic en él.

  • _blank: Abre el enlace en una nueva ventana o pestaña.
  • _self: Abre el enlace en la misma ventana (valor por defecto).
  • _parent: Abre el enlace en el marco padre.
  • _top: Abre el enlace en la ventana principal del navegador.

Atributo download

El atributo download permite que un enlace descargue un archivo en lugar de abrirlo en el navegador.
